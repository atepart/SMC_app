# Расчётная модель SMC_app

Документ фиксирует проверенную связь между параметрами интерфейса, элементами схемы и legacy-расчётом `backend/main.py`. Внутренние единицы не изменены при переносе: частота — GHz, длины — m (кроме явно названных `_um`), энергия — eV, `RnA` — Ω·µm², `C0` — F/µm².

## Последовательность расчёта

1. Для электродов EL1/EL2 вычисляется нулевая щель
   `Δ₀ = α·kB·Tc/2`, затем температурная `Δ(T)` итерацией strong-coupling approximation.
2. По `Δ(T)`, `T` и нормальной проводимости `σ0` строятся таблицы комплексной проводимости Mattis–Bardeen. Из них для каждой частоты получаются поверхностные импедансы плёнок с толщинами `d_top` и `d_bot`.
3. Из микрополосковых линий, ступенчатых трансформаторов, slot-antenna DC-block и radial stub собираются ABCD-матрицы. Порядок умножения сохранён из legacy: `Mex4 · Mex3 · Mdcb · Mex2 · Mex1`.
4. Терминальные импедансы — источник `Zffo` и нагрузка `Zsis(f)`. По полной ABCD-матрице рассчитывается transducer `S21`, затем `10·log10(S21)`.

Зависимость `Δ₀` от `α` — исправление из письма от 2026-07-07. При значениях по умолчанию `α=3,54`, `Tc=9,5 K` получается около `1,45 meV`, то есть старый численный результат сохраняется, но `α` больше не является неиспользуемым параметром.

Численная проверка переноса выполнена на всех 160 legacy-точках `100…895 GHz`. При `α=3,5424809443301877`, точно восстанавливающем legacy-константу `Δ₀=1,45 meV`, максимальное отличие нового и старого `S21` равно `4,3·10⁻¹⁴ dB` (машинная погрешность). При пользовательском значении по умолчанию `α=3,54` максимальное отличие от старой константы составляет `0,0507 dB`, среднее — `0,0087 dB`; это ожидаемый эффект исправленной зависимости, а не расхождение реализации.

Для каждого трансформатора число дискретных срезов равно `floor(|Wend-Wstart|/dW)+1`, длина каждого среза — соответствующий `dL`. В `Mex4` короткая линия, как и в legacy, вычисляется на опорной частоте `f0`, а radial shunt — на текущей частоте sweep.

## DC-block и SIS

DC-block представлен взаимной slot/dipole-связью двух изолированных folded-slot проводников. Эквивалентная симметричная матрица состоит из семи множителей:

`bridge/2 · open MSL · slot shunt · slot line · slot shunt · open MSL · bridge/2`.

Такой элемент передаёт ВЧ-мощность, но разрывает постоянный ток между ФФО и детектором. Radial stub далее создаёт широкополосное ВЧ-короткое замыкание; короткий участок микрополоска преобразует его в эффективную индуктивность, компенсирующую ёмкость SIS.

Собственная модель перехода:

`Zsis = 1 / (1/RnA + j·2πf·C0) / S + j·Lsis`.

В UI `C0` показывается в pF/µm²: `8,3·10⁻¹⁴ F/µm² = 0,083 pF/µm²`. В backend и файле дизайна остаётся F/µm², поэтому результаты старых расчётов и сохранённых дизайнов не меняются.

## Изменение `t_prox`

В письме от 2026-07-06 описана будущая дополнительная параллельная ёмкость непокрытого SiO₂ участка возле SIS-перехода. Она должна вычисляться как плоский конденсатор с толщиной и диэлектрической проницаемостью анодизационного слоя. Это не то же самое, что `C0` туннельного барьера.

В текущую модель `t_prox` не добавлен: приложенного Mathcad-файла с окончательной формулой, геометрическим множителем и согласованным значением нет, а в переписке изменение прямо отложено «на позже». После получения файла нужен отдельный регрессионный набор Mathcad ↔ Python на нескольких образцах HD16/HD35.

## Сверенные источники

- V. P. Koshelets, S. V. Shitov, *Integrated superconducting receivers*, DOI [10.1088/0953-2048/13/5/201](https://doi.org/10.1088/0953-2048/13/5/201): архитектура FFO–SIS, характерная удельная ёмкость `≈0,08 pF/µm²`, роль сверхпроводящих плёнок.
- S. V. Shitov et al., *A Superconducting Planar Integrated Receiver for the Frequency Range 430–480 GHz* ([ISSTT proceedings](https://www.nrao.edu/meetings/isstt/papers/1995/1995324337.pdf)): folded-slot DC-block как band-pass элемент без гальванической связи.
- F. V. Khan et al., *Terahertz-range on-chip local oscillator based on Josephson junction arrays for superconducting quantum-limited receivers*, DOI [10.3762/bjnano.16.158](https://doi.org/10.3762/bjnano.16.158): slot-antenna DC-block между генератором и SIS, radial-stub компенсация паразитной ёмкости и сопоставление рассчитанного `S21` с экспериментом.
- J. Zmuidzinas et al., материалы ISSTT по интегральным SIS tuning circuits ([PDF](https://www.nrao.edu/meetings/isstt/papers/1993/1993050058.pdf)): `Rn || Cj`, последовательные трансформаторы и radial stub как ВЧ-короткое для компенсации `Cj`.
