### `WP-067` — величины тока на правой оси по ответам владельца (вопросы из `WP-064`)

- Результат: точки с I ≤ 0 по-прежнему не показываются (ответ «а»). Столбец «Log» означает, что в файле уже lg I²: величины «I², A² Log», «I², mA² Log», «I², µA² Log» рисуются как есть, без удвоения; «I/I_g Log» без квадрата убирается. Добавляются «(I/I_g)²» (значения уже квадрат, логарифмическая шкала без повторного возведения) и «(I/I_g)² Log» (как есть, линейная шкала). «I/I_g» по-прежнему возводится в квадрат.
- Критерии готовности: значения правой оси для всех величин (I, I/I_g — 2·lg; (I/I_g)² — lg; «Log» — как есть, с пересчётом mA² → µA²); подсказка по заголовку узнаёт `^2`/`²` и не предлагает логарифм без квадрата; подписи осей, полей Y2, размах в dB и подпись у курсора; тесты `test_trace_files`, `test_plot_curves`; ручной импорт в настоящем приложении — I/I_g, (I/I_g)², (I/I_g)² Log, µA² Log, все значения ≤ 0.

### `WP-065` — масштаб интерфейса (#13, варианты 1 + 2)

- Результат: меню «Вид → Масштаб» с пресетами «Мелкий», «Обычный» (как сейчас), «Крупный», «Максимальный» и сочетаниями Ctrl+= / Ctrl+− / Ctrl+0 — масштабирует весь интерфейс сразу, без перезапуска, и запоминается.
