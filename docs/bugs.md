# Дефекты

Здесь находятся только подтверждённые открытые дефекты. Правила ведения описаны в [`AGENTS.md`](../AGENTS.md).

## Открытые

- `BUG-012`, `WP-016` — архив Windows x86 фактически содержит x64-сборку; приоритет средний, исправляется в выпуске 006.
  - Окружение: GitHub Actions, Windows 2022, setup-python 3.11.
  - Воспроизведение: матрица содержит x86/x64, но setup-python не получает architecture, оба используют один x64 интерпретатор. PySide6 6.8.2.1 выпускает Windows wheel только win_amd64.
  - Ожидается: имя архива соответствует бинарникам; фактически: дублирующий x64 с названием x86. Исправление: три поддерживаемые платформы, явная architecture; проверка ZIP/PE/Mach-O в CI и после загрузки.
