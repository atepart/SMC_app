# Дефекты

Здесь находятся только подтверждённые открытые дефекты. Правила ведения описаны в [`AGENTS.md`](../AGENTS.md).

## Открытые

- `BUG-001` — команды `uv run` не запускаются из корня проекта.
  - Приоритет: высокий.
  - Статус: подтверждён, запланировано исправление в `WP-001`.
  - Окружение: macOS, `uv 0.8.0`.
  - Шаги воспроизведения: из корня выполнить `rtk uv run python --version`.
  - Ожидаемый результат: `uv` создаёт/использует проектное окружение и запускает Python.
  - Фактический результат: `error: No project table found in pyproject.toml`.
  - Влияние: невозможно выполнить обязательные тесты и запуск приложения по принятому процессу.
