# Дефекты

Здесь находятся только подтверждённые открытые дефекты. Правила ведения описаны в [`AGENTS.md`](../AGENTS.md).

## Открытые

- `BUG-007` — повторно наблюдался непостоянный `SIGABRT` при уничтожении тестового Qt-окна после PNG export.
  - Приоритет: средний; статус: открыт повторно после контрольного прогона при `WP-014`.
  - Окружение: macOS arm64, Python 3.11.13, PySide6 6.8.2.1, offscreen Qt.
  - Воспроизведение: полный `rtk uv run pytest`; воспроизводится не каждый раз (перед выпуском `004` полный набор прошёл дважды).
  - Ожидалось: 32 теста завершаются успешно. Фактически: после шести тестов parameter panel процесс падает в `tests/test_parameter_panel.py:40`, `sendPostedEvents(DeferredDelete)`.
  - Изменение `gc.collect()` в `WP-012` не устранило все варианты проблемы жизненного цикла тестовых QtAds/pyqtgraph-объектов. В нативном приложении этот сценарий не воспроизведён.
