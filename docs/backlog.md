# Backlog

Здесь находятся идеи и отложенные задачи, ещё не взятые в работу. Правила ведения описаны в [`AGENTS.md`](../AGENTS.md).

## Идеи и улучшения

- `BL-001` — уточнить окончательные названия и состав подблоков параметров после получения перечня от владельца.
  - Ценность: интерфейс будет использовать предметную терминологию команды и однозначно соответствовать чертежу.
  - Объём: небольшой после получения спецификации; зависит от будущего перечня названий.
- `BL-002` — дополнить панель формул библиографическими источниками и пояснениями после получения списка учебников/ссылок.
  - Ценность: расчёт станет проверяемым и пригодным как инженерная документация.
  - Объём: средний; зависит от будущих материалов владельца.
- `BL-003` — после `WP-008` добавить редактирование параметров выбранного элемента непосредственно поверх схемы.
  - Ценность: выбор геометрического элемента сможет открывать его связанные поля и применять изменения обратно в `S21Config` с обновлением панели и preview.
  - Объём: средний/большой. Текущий `QGraphicsSvgItem` является одним объектом без hit-testing отдельных SVG-групп; сначала нужны стабильные element ID и двусторонняя таблица `geometry element ↔ config fields` из `WP-008`, затем отдельные overlay-редакторы и валидация.
  - Зависимости: подробное следующее ТЗ по группировке/названиям и завершённый `WP-008`; прямое drag-изменение без этих контрактов неоднозначно.
- `BL-004` — проверить импорт HFSS (`WP-040`) на настоящем файле `.tab` от владельца и положить его в `tests/data/`.
  - Ценность: сейчас чтение проверено только на синтетическом файле в формате из ТЗ; реальный экспорт может иметь другие заголовок, разделители или единицы.
  - Объём: небольшой; зависит от присланного владельцем примера (он «на почте»).
  - Единицы частоты после `WP-052` подтверждаются при каждом импорте; проверка настоящего экспорта HFSS остаётся отдельным пунктом.

- `BL-006` — импорт кривых прямо из проекта Origin `.opj` (после `BUG-026` такой файл даёт понятное сообщение с подсказкой выгрузить лист в текст).
  - Ценность: владелец присылает сравнения и эксперимент в Origin; не нужно выгружать листы вручную.
  - Объём: средний — формат закрытый, нужен выбор листа и столбцов, проверка на файлах разных версий Origin (разбор одного файла уже есть: `docs/screenshots/MATHCAD-HD35-H2_n/opj_read.py`, локально).
  - Зависимости: решение владельца, нужен ли этот импорт; единицы частоты — общий диалог `WP-052`.
