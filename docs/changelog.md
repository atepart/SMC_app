# Changelog

Все значимые изменения проекта документируются в этом файле. Формат основан на [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## Unreleased

### Added

- `WP-004` — панель параметров защищена от случайного редактирования и получила файлы дизайна.
  - Колесо меняет `QDoubleSpinBox` только после явного клика и снова блокируется при потере фокуса; без клика колесо продолжает прокрутку длинной формы.
  - Все расчётные группы независимо сворачиваются, а Actions с preview, расчётом и сохранением закреплён под scroll area.
  - В названиях используются `α`, `σ`, `Δ`, `ε`; для метрических размеров показано отдельное неизменяемое поле инженерного порядка `×10^-6 m`.
  - Кнопки Actions сохраняют и загружают версионный UTF-8 JSON «Дизайн», хранящий параметры в backend-единицах; последний успешный каталог запоминается.
  - Проверка: Qt-тесты воспроизводят колесо до/после клика, сворачивание, неподвижность Actions и UI round-trip; отдельные тесты проверяют схему и ошибочные форматы файла.
  - Скриншот: [`docs/screenshots/WP-004/safe-parameters.png`](screenshots/WP-004/safe-parameters.png).
- `WP-003` — интерфейс переведён на управляемое рабочее пространство `PySide6-QtAds` по образцу RnSApp.
  - Параметры, схема, график и лог расчёта стали независимыми перемещаемыми, изменяемыми по размеру и закрываемыми dock-панелями.
  - В toolbar добавлены живой список «Виджеты» и восстановление стандартной раскладки; состояние панелей и геометрия окна сохраняются в `QSettings` с версией формата.
  - Кнопка Home схемы стала компактной иконкой в левом нижнем углу; SVG автоматически подгоняется после изменения размеров dock-панели, не сбрасывая пользовательский zoom.
  - Добавлена совместимая связка `PySide6 6.8.2.1` и `PySide6-QtAds 4.3.1.4` в `uv`-окружение и legacy-файл зависимостей.
  - Проверка: Qt-интеграционные тесты меняют раскладку через настоящий `CDockManager`, закрывают и возвращают панели через список, проверяют пропорции, SVG-fit и версионное восстановление настроек.
  - Скриншот: [`docs/screenshots/WP-003/dock-workspace.png`](screenshots/WP-003/dock-workspace.png).
- `WP-000` — добавлены правила разработки, тестирования, реальной проверки GUI, ведения рабочего плана, дефектов, backlog и changelog.
  - Проверка: структура и ссылки Markdown проверены вручную; `rtk git diff --check` выполнен успешно.
  - На момент первого документационного коммита Python-проверки были заблокированы исходным `BUG-001`; ниже зафиксировано его исправление в `WP-001`.

### Fixed

- `WP-002`, `BUG-002` — SVG-preview перестроен по предоставленному инженерному референсу и реальной ABCD-цепочке.
  - Удалены два условных одинаковых блока; показана физическая последовательность `Mex01 → Mex02 → Mdcb → Mex03 → Mrad/MLsis → Mex04 → 50 Ω`.
  - Отрисованы все семь расчётных трансформаторов, MSL-секции, симметричный slot-coupled DC-block, парный radial stub и вложенные пунктирные рамки матриц.
  - Длина каждого трансформатора повторяет backend-формулу числа дискретных срезов; порядок цепочки, поправка `DW`, radial-формула и назначение элементов описаны в docstring/комментариях.
  - Проверка: тесты подтверждают состав групп, количество трансформаторов, DC/radial-элементы, формулу длины и SVG-разметку; приложение запущено нативно и preview визуально сверен с референсом.
  - Скриншот: [`docs/screenshots/WP-002/full-network-preview.png`](screenshots/WP-002/full-network-preview.png).
- `WP-001`, `BUG-001` — восстановлен воспроизводимый цикл разработки через `uv`.
  - Добавлены метаданные проекта, lock-файл, декларативные runtime/dev-зависимости и установка пакета в editable-режиме.
  - Настройки Ruff и Black согласованы на длине строки 120; существующий Python-код приведён к единому формату Black/isort.
  - Добавлены два доменных теста и Qt-интеграционный тест, который открывает настоящее главное окно, кликает переключатель материалов и кнопку `Update Preview`, проверяет состояния виджетов и SVG.
  - Проверка: `uv sync`, Ruff, Black, isort, 3 теста, `compileall` и `git diff --check` проходят успешно.
  - Ручная проверка: приложение запущено нативно через `rtk uv run python -m aocapp`; главное окно и начальный SVG-preview отображаются корректно.
  - Скриншот: [`docs/screenshots/WP-001/app-launch.png`](screenshots/WP-001/app-launch.png).
