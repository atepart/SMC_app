# Changelog

Все значимые изменения проекта документируются в этом файле. Формат основан на [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## Unreleased

### Added

- `WP-015` — трансформаторы редактируются через W1, W2 и общую L; параметры разбиения подбираются автоматически по формуле GitHub #6.
  - n и |W1−W2|/n целые, dl лежит в 0,5…1,5 µm; среди допустимых вариантов предпочитаются n=2 и n=4. Невозможные сочетания сообщают номер элемента и блокируют preview, расчёт и сохранение. Исходное разбиение нетронутых старых файлов сохраняется точно.
  - Для таблицы S21 вводится только имя файла; папка выбирается системным диалогом и запоминается отдельно от файлов параметров. Поля используют всю доступную ширину панели.

### Changed

- `WP-015` — схема и группы параметров используют сквозные номера 1–12 слева направо от ФФО. W1/W2 соответствуют левому/правому краю каждого перехода; внутренние ID и ABCD-порядок сохранены.
  - Полная SVG-легенда содержит W1/W2/L переходов, W/L линий, размеры DC-break, всех линий радиального узла и SIS. Подписи, tooltips и расчётная документация приведены к текущей форме. [Векторная схема](screenshots/WP-015/structure.svg).
  - Шаг RnS равен 0,5 Ω·µm²; частотных полей, включая Home X, — 10 GHz, полей частотного шага — 1 GHz; длин/ширин структуры — 0,5 µm. Толщины слоёв сохраняют прежний мелкий шаг.
  - Локальный `matcad/` исключён из Git по указанию владельца; файлов каталога в индексе не было.

### Fixed

- `WP-015`, `BUG-009` — σ отображается с фиксированным порядком ×10⁶ 1/(Ω·m), принимает точку/запятую и сохраняет нули при вводе. Например, 0,975 передаётся как 975 000 в backend и файл параметров.
- `WP-015`, `BUG-010` — отображаемая L учитывает тот же допуск конечного среза 0,01 µm, что и backend. Старый случай W=6→17,995 µm, n=6, dl=0,9 µm теперь показывает расчётную L=2,7 µm вместо 1,8 µm.
  - Проверка `WP-015`: Ruff, Black, isort, 53 теста, compileall и diff-check. Тесты проверяют все семь переходов, порядок/направление/размеры SVG, реальные backend-срезы в обе стороны, границы dl, невозможные/равные ширины, старые файлы, клавиатурный ввод σ и запись через worker в выбранную папку.
  - Текущий модуль запущен нативно через uv; свежая временная macOS-сборка проверена вручную: σ=0,975 с синхронизацией; W1=15/W2=49/L=10 µm → n=2/dl≈0,556 µm; L=100 µm с ошибкой; preview/легенда; сохранение/загрузка параметров; системный выбор /tmp и восстановление папки после перезапуска; две таблицы S21 по 160 конечных точек и отображение кривой. SciPy сообщает прежнее предупреждение roundoff quadrature, расчёт завершается успешно.
  - Скриншоты: [σ](screenshots/WP-015/sigma.png), [пересчёт](screenshots/WP-015/transformer-preview.png), [ошибка](screenshots/WP-015/invalid-transformer.png), [S21](screenshots/WP-015/s21-result.png), [папка/полная легенда](screenshots/WP-015/output-folder.png), [итоговые поля](screenshots/WP-015/output-fields.png).

- `WP-014`, `BUG-008` — восстановлена публикация релиза `004` после ошибок загрузки `Error creating asset temp dir` и `Error saving asset`.
  - Обе недостающие сборки последовательно загружены через GitHub CLI; четыре ZIP проверены на целостность, размер и совпадение SHA-256 с GitHub. [Релиз 004](https://github.com/atepart/SMC_app/releases/tag/004) опубликован с описанием изменений и отмечен Latest.
  - Использовавшийся `softprops/action-gh-release@v3` уже соответствовал последнему `v3.0.3` (`efb35369e0ad2afab669f228072c1b0d510eae64`). Обновление версии не требовалось; точную внутреннюю причину отказа сохранения GitHub не сообщил.
  - Для будущих запусков включены последовательная загрузка (`preserve_order`), сохранение существующих файлов при повторе и отказ при отсутствующем архиве. Настройки сверены с исходником action; YAML проверен парсером. Исходный неуспешный Actions run сохранён, тег `004` не перемещался; новые настройки будут применяться к следующим тегам.
  - Проверка: Ruff, Black, isort, 32 теста, compileall и diff-check. GUI не менялся; нативные сценарии релиза проверены в `WP-012`/`WP-013`. Во время дополнительного прогона повторно проявился непостоянный сбой очистки тестовых Qt-объектов; `BUG-007` снова открыт, последующий и итоговый полные прогоны успешны.

### Fixed

- `WP-012`, `BUG-006` — схема уточнена по встроенному рисунку четырёх листов Mathcad HD35 и пользовательскому `structure_clean.svg`.
  - Радиальный узел использует настоящие квадратичные SVG-кривые, наклонные стороны и ступенчатую горловину из нового референса. SIS показан прямоугольником с кружком слева от радиала; выноски SIS/MLsis разнесены. Лишний крайний левый фланец/подвод исключён.
  - DC-break направлен вниз и остаётся гальванически раздельным. Номера 3…1 / 4…1 / 5…1 привязаны к конкретным секциям; легенда объясняет их типы, имена приложения и текущие размеры.
  - Начальный вид показывает крупную схему; переключатель «С обозначениями» открывает полный рисунок с легендой. SVG явно обозначен как схема не в масштабе.
  - В `calculation-model.md` зафиксированы источник/хеш рисунка, соответствие номеров и отличие H1 (3/2/3 секции вместо 3/4/5); расчётные формулы и параметры вариантов не заменялись.
  - `BUG-007` — расширенный Qt-набор выявил `Fatal Python error: Aborted` в `pyqtgraph/AxisItem.py:416 resizeEvent` при создании очередного окна. Fixture собирает циклы предыдущего окна до создания новых graphics items; полный повторный прогон завершился успешно.
  - Проверка: Ruff, Black, isort, 32 теста, compileall, diff-check. Нативное приложение запущено через uv; ручная проверка выполнена в временной сборке того же исходного кода: Update Preview, легенда, изменение высоты dock-панели, Wslot=DW с предупреждением и восстановление Wslot=4 µm.
  - Ограничение среды: Qt в sandbox сообщает `Incompatible processor … neon`; GUI и Qt-тесты выполнялись вне sandbox, uv использовал `/tmp/aoc-uv-cache` и существующее окружение (`--no-sync`).
  - Скриншоты: [схема](screenshots/WP-012/overview.png), [с обозначениями](screenshots/WP-012/annotated-structure.png), [ошибка щели](screenshots/WP-012/invalid-slot.png). Сохранены [оригинал Mathcad](screenshots/WP-012/mathcad-reference.png) и [векторный референс](references/structure-clean-source.svg).
- `WP-011`, `BUG-004` — исправлены топология DC-break и наложения в аннотированной SVG; прежняя folded-U интерпретация из `WP-009/WP-010` признана ошибочной и заменена по технологическому эскизу владельца.
  - DC-развязка теперь состоит ровно из двух встречных гальванически изолированных проводников с прямыми параллельными гранями щели, короткими плечами и отдельными левым/правым фидерами; внешних U-образных возвратов нет.
  - `Wslot` и `Lslot` показаны отдельными двусторонними размерными стрелками; исходные и эффективные после `DW` размеры остаются в реестре справа.
  - Индивидуальные выноски узких `T*`/`MSL*` удалены с металлизации: физический порядок каждой секции теперь записан одной строкой внутри соответствующей рамки `Mex01`–`Mex03`.
  - В реестр добавлен отдельный блок назначения: согласующие каскады, slot-antenna `Mdcb`, ВЧ-замыкатель `Mrad`, индуктивная настройка `MLsis` и модель SIS `Rn || C0 + L`.
  - Документация и docstring расчёта сверены с рис. 1 статьи Хана и соавторов 2023 года и рис. 3 обзора 2025 года: DC-break — распределённая щелевая антенна, а не подмена одним сосредоточенным конденсатором.
  - `BUG-005` — тестовый `QApplication` закреплён на всю сессию и явно уничтожается после отложенных QtAds-объектов, поэтому успешный UI-прогон больше не завершается `SIGABRT` при shutdown.
  - Проверка: Ruff, Black, isort, 27 тестов, `compileall`, `git diff --check`; текущий исходный модуль запущен отдельно, нативный Qt/Cocoa preview визуально проверен.
  - Скриншот: [`docs/screenshots/WP-011/annotated-structure.png`](screenshots/WP-011/annotated-structure.png).
- `WP-010`, `BUG-003` — SVG-схема приведена к однозначному инженерному виду по пользовательским эскизам и опубликованной интегральной структуре.
  - Необъяснённые цифры `1…5` заменены физическими именами `T1…T7`, `MSL4…MSL8`, `DC-break`, `SIS` и `Radial shunt ×2`; заголовки расчётных матриц вынесены на отдельные горизонтальные уровни.
  - DC-break показан двумя зеркальными гальванически разделёнными folded-U секциями; `Wslot` и `Lslot` подписаны непосредственно на узле, а отдельная таблица справа перечисляет все геометрические входы, эффективные ширины после `DW` и вычисленные длины трансформаторов.
  - Размерные наконечники разворачиваются навстречу друг другу через SVG `auto-start-reverse`; вертикальная подпись `Lslot` повёрнута вдоль размерной линии, геометрия, размеры и пояснения визуально разнесены.
  - Неиспользуемые legacy-поля условных `Block1/Block2` скрыты из формы, но оставлены в `S21Config` для чтения старых файлов; добавлена проверка физического условия `Wslot > DW`.
  - «Дизайн» переименован в «Параметры SMC_app»: интерфейс и документация явно сообщают, что `.aocdesign/.json` хранит входы расчёта, обновляет форму/SVG, не является Mathcad и требует отдельного `Run S21`.
  - В [`docs/calculation-model.md`](calculation-model.md) добавлена расшифровка рис. 3 статьи Ф.В. Хана и соавторов, связь изображения с ABCD-группами и проверяемый процесс Mathcad ↔ SMC_app.
  - Проверка: Ruff, Black, isort, 27 тестов, `compileall`, `git diff --check`; нативный Qt/Cocoa preview на дефолтных параметрах и ошибочный сценарий `Wslot ≤ DW`.
  - Скриншот: [`docs/screenshots/WP-010/annotated-structure.png`](screenshots/WP-010/annotated-structure.png).
- `WP-009` — выполнено интерфейсное ТЗ GitHub issue `#4` и проверена расчётная модель.
  - Группы параметров получили поворачиваемые disclosure-треугольники и порядок `LO → Backend Grid → SIS`; `C0` показывается как `0,083 pF/µm²`, оставаясь `8,3·10⁻¹⁴ F/µm²` в backend и файлах дизайна.
  - Tooltip графика показывает частоту и `S21`; Home по умолчанию и после перерисовки остаётся `100…900 GHz`/`−20…0 dB`, шаги полей равны `50 GHz`/`5 dB`, диапазон от 1 THz получает единицу `THz`, а не `kGHz`.
  - Preview подписывает вход `ФФО`; DC-block перерисован по двум изображениям issue как две гальванически раздельные folded-slot U-секции без ложных пластин/перемычки.
  - Расчёт `Δ(α,Tc)`, Mattis–Bardeen, SIS, radial stub, DC-block и ABCD-цепь снабжён предметными docstring/комментариями и описан в [`docs/calculation-model.md`](calculation-model.md) со сверенными источниками.
  - Полная кривая из 160 точек совпала с legacy до `4,3·10⁻¹⁴ dB` при `α`, воспроизводящем старое `Δ₀=1,45 meV`; при исправленном дефолте `α=3,54` среднее ожидаемое отличие от константного legacy — `0,0087 dB`.
  - Будущая ёмкость анодизационного участка `t_prox` не смешана с `C0`: для неё нужен приложенный Mathcad и отдельная проверка HD16/HD35. Возможность прямого редактирования схемы оценена и зафиксирована как `BL-003` после element bindings из `WP-008`.
  - В приложение и сборку подключён побайтно исходный пользовательский `smc-logo.png`; ICO содержит только уменьшенные 16/24/32/48 варианты, без апскейла или генеративной перерисовки.
  - Проверка: Ruff, Black, isort, 25 тестов, `compileall`, `git diff --check`; нативный Qt/Cocoa-запуск и клики по material toggle/preview, сворачиванию групп, Home/tooltip и граничной THz-шкале.
  - Скриншот: [`docs/screenshots/WP-009/issue-4-interface.png`](screenshots/WP-009/issue-4-interface.png).
