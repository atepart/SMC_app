- `WP-040` — по [GitHub #11](https://github.com/atepart/SMC_app/issues/11) импорт расчёта HFSS на график.
  - Пункт «Открыть файл → HFSS» (между «Параметры SMC_app» и «Experiment»), фильтр диалога `*.tab`.
  - Формат: первая строка — заголовок, обычно `"Freq [THz]"\t"dB(S(2,1)) []"`, с кавычками или без. Разделители — табуляция, пробелы, запятая или точка с запятой. Пустые строки пропускаются, BOM и CRLF допускаются, точки сортируются по частоте.
  - Частота переводится в GHz по единице из заголовка (`[THz]` → ×1000; `[GHz]`/`[MHz]` тоже понимаются). Если единицы в заголовке нет — считается THz, как в ТЗ. Вторая колонка — S21 в dB.
  - Ошибки — диалог «Ошибка импорта HFSS» с номером строки: нечисловое значение, не два столбца, NaN/бесконечность. Отдельные сообщения для пустого файла и файла только с заголовком. Ранее загруженная кривая HFSS при ошибке остаётся.
  - Кривая `HFSS` на левой оси S21, стиль `WP-039`: чёрная пунктирная 2 px, в тёмной теме светло-серая (#e6e6e6). В легенде между prev и exp, с галочкой.

  - Тестовый файл `tests/data/hfss_s21_example.tab` синтетический (81 точка, 0.1…0.9 THz) в формате HFSS. Настоящий пример владельца ещё не получен. Для этого файла в `.gitignore` сделано исключение из правила `*.tab`.
